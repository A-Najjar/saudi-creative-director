# قوالب العرض

**قواعد** لكل القوالب:

- **ابدأ** كل سطر ونقطة بكلمة عربية.
- **خل** المصطلحات الإنجليزية في وسط السطر أو داخل جدول.
- **لا** تضف شروطاً أو توصيات ميزانية ما طلبها المستخدم.
- **اكتب** الافتراضات في الأعلى لو افترضت شيئاً.

---

## القالب 1: أفضل ثلاث أفكار (الدورة الكاملة)

```
## البريف باختصار
[فقرة: المنتج، الجمهور، الهدف، القيود، المناسبة]

**الافتراضات**: [لو فيه]
**الوضع**: [سريع / قياسي / عميق]

## الإنسايت
[الجمهور] يبي [كذا]، بس [كذا يمنعه]، لأن [السبب].

## الأفكار

### 1. [اسم الفكرة]
**الفكرة في جملة**: ...
**وش يشوفه الناس**: [مشهد ملموس في سطرين أو ثلاثة]
**القنوات**: ...
**السطر الدعائي**: "..."، والبديلان: "..." و"..."
**الدرجة**: [مدى]، ثقة [عالية/متوسطة/منخفضة]
**رأي الحكم البارد**: [أضعف نقطة في سطر]
**الامتثال**: ...
**أول ثلاث خطوات**: ١... ٢... ٣...

### 2. ...
### 3. ...

## اتجاهات رفضناها
- **[اسم]**: [سبب الرفض في سطر]

## التوصية
[أي فكرة نطور وليش، في فقرة قصيرة]

## يحتاج تحقق
[الافتراضات المهمة غير المؤكدة لو فيه]
```

## القالب 2: صفحة الكونسبت الواحدة

```
# [اسم الفكرة]

**في جملة**: ...

**الإنسايت**: ...

**الفكرة**: [فقرة تشرح الآلية]

**كيف تعيش**:
- **الإطلاق**: ...
- **الانتشار**: ...
- **الاستمرار**: ...

**ليش بتنجح**: [مربوطة بسابقة أو دليل]

**الشعور المستهدف**: [المستوى والاسم بالضبط]

**السطر الدعائي**: "..."

**مقياس النجاح**: [مؤشر واحد أو اثنين مربوطين بالهدف التجاري]

**المخاطر**: [من تمرين ما قبل الفشل]

**الامتثال**: ...

**الدرجة**: [مدى]، ثقة [...]
```

```
**ركائز المنصة**:
- **الركيزة 1**: ...
- **الركيزة 2**: ...

**أمثلة تنفيذ عبر السنة**:
| المناسبة | التنفيذ |
|---|---|

| اليوم الوطني | ... |
| موسم المنتج | ... |

**النبرة**: ...
**وش ما نسويه أبداً**: ...
```
